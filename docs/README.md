# 《溯源者：文明环境》— 项目说明

本文档面向**第一次打开仓库**的同学或答辩老师，概括**游戏是什么、技术栈、目录与模块分工**；课设细则、接口表与分工排期见文末「延伸阅读」链接。

---

## 项目是什么

《**溯源者：文明环境**》是一款**国风题材、类《杀戮尖塔》的 Roguelike 卡牌**单机：玩家在**层状地图**上选择路线，进入**战斗、事件、商店、休息、宝箱**等节点，通过**组牌、能量与资源管理**推进层数直至 Boss。**静态内容**（卡牌、怪物、事件等）由 **`data/`** 下 JSON 等表驱动；**程序**负责地图、战斗流程、牌堆、事件脚本与存档。

---

## 技术栈与运行环境

| 项目 | 说明 |
|------|------|
| 语言与标准 | **C++17** |
| 图形与输入 | **SFML 3.x**（窗口、事件、2D 绘制） |
| 工程 | **Visual Studio** 解决方案（`*.sln` / `*.vcxproj`） |
| 数据 | **`data/`**：卡牌 / 怪物 / 事件等表；运行时由 **DataLayer** 加载 |
| 资源 | **`assets/`**：字体、立绘、UI、音视频等 |

入口为 **`src/main.cpp`**：创建窗口 → **`GameFlowController::initialize`**（加载数据、注册卡牌效果、选角与地图初始化）→ 开始界面与 **`run`** 主循环（地图 / 战斗 / 事件等）。部分过场依赖本机 **`ffplay`**（可选，见 `main.cpp` 注释）。

构建：在仓库根目录用 Visual Studio 打开 **`Tracer-Civilization-Environment.sln`** 编译；若仓库提供 **`build.bat`**，可按脚本说明一键生成（以本机脚本为准）。

## 程序模块（与课设分工对应）

| 模块 | 目录（典型） | 职责（一句话） |
|------|----------------|------------------|
| **数据层** | `DataLayer` | 读表、`get_card_by_id` / 怪物 / 事件等查询 |
| **地图** | `MapEngine` | 地图拓扑、层与节点、可达性、地图 UI 配合 |
| **卡牌** | `CardSystem` | 跨战斗 master 牌组、单场抽/手/弃/耗、洗牌与出牌效果注册 |
| **战斗** | `BattleEngine` | 单场回合、能量、意图、伤害与战斗 UI 驱动 |
| **事件等** | `EventEngine` | 事件 / 商店 / 休息等分支与改牌回调 |
| **主流程** | `GameFlow` | 选角、进房顺序、检查点与存档、场景分发、主循环编排 |
| **效果与 UI** | `Effects`、`UI` 等 | 卡牌效果实现、卡面与其它界面表现 |

五人字母分工（A～E）与依赖关系见 [课设分工与排期.md](课设分工与排期.md)。
